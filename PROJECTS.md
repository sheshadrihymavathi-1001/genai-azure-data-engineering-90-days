# GenAI + Azure Data Engineering Projects

This repository contains hands-on GenAI projects built from a Data Engineering perspective.

## Project strategy

GenAI is treated as an extension of the data platform, not as a separate toy application. The projects focus on reliable ingestion, document processing, chunking, retrieval, RAG, evaluation, monitoring, and production-oriented design.

## Projects

### Project 01 — E-commerce Document Intelligence
Build the ingestion and preparation layer for enterprise documents such as return, warranty, shipping, seller policies, and product manuals.

### Project 02 — E-commerce RAG Assistant
Build a customer-facing RAG assistant that answers questions using authoritative enterprise documents and retrieved context.

### Project 03 — Metadata-Driven GenAI Pipeline
Generalize the solution using metadata, configuration-driven processing, auditability, restartability, and scalable orchestration.

## Learning environment

The hands-on implementation is designed for Databricks Free Edition where possible. Production-only Azure services will be documented separately when they cannot be reproduced in the free environment.

## Repository principles

- Business problem before technology
- Data validation before AI processing
- Explicit source authority and document versioning
- Reproducible notebooks and SQL
- Data quality and failure handling
- Security and governance considerations
- Architecture and interview-ready explanations
